# TOEIC List

TOEIC学習のための単語・フレーズリスト管理プロジェクト

## 概要

このリポジトリは、TOEIC（Test of English for International Communication）スコア930点を目指す学習者のための学習記録管理プロジェクトです。

単語、イディオム、文法テクニックの学習履歴をCSV形式で記録・管理し、最終的に暗記アプリへインポートするためのデータファイルを作成します。

### 対象者

- TOEICスコア930点を目指している学習者
- 体系的に学習記録を残したい方
- 暗記アプリと連携した効率的な学習を行いたい方

## 特徴

- **学習履歴の一元管理**: 単語、イディオム、文法テクニックを一箇所で管理
- **CSV形式での記録**: 汎用性が高く、他のツールとの連携が容易
- **暗記アプリ対応**: 学習データを暗記アプリに直接インポート可能
- **重要度管理**: 各項目に重要度を設定し、優先順位を明確化
- **履歴追跡**: 登録日・更新日を記録し、学習の進捗を可視化

## データ形式

### 単語・イディオム

CSV形式で以下の項目を管理します：

```csv
単語・イディオム（英語）,単語・イディオム（日本語）,品詞,重要度,登録日,更新日
```

**例:**
```csv
単語・イディオム（英語）,単語・イディオム（日本語）,品詞,重要度,登録日,更新日
accomplish,成し遂げる,動詞,5,2025-01-15,2025-01-15
in advance,事前に,イディオム,4,2025-01-15,2025-01-15
```

## 使い方

1. 学習した単語やイディオムをCSVファイルに追加
2. 重要度や品詞などの情報を記録
3. 定期的に復習し、必要に応じて更新日を更新
4. 完成したCSVファイルを暗記アプリにインポート
