# TOEIC List

TOEIC学習のための単語・フレーズリスト管理プロジェクト

## 概要

このリポジトリは、TOEIC（Test of English for International Communication）の学習に役立つ単語やフレーズをまとめたものです。

## 特徴

- TOEICに頻出する単語・フレーズの収録
- カテゴリ別・レベル別の整理
- 学習効率を高める構成
